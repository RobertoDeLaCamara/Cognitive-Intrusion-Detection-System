## How a deployment happens here

- `docker-compose.yml` uses `build:` (no `image:`) for `api`, `detector`, `dashboard`, `demo-seed`. A deploy on a compose host is therefore `git pull` plus `docker compose up -d --build`, not an image pull.
- Jenkins pushes `192.168.1.147:5000/cnds:<BUILD_NUMBER>` and `:latest` only from master. **If any host runs this image from the registry with Watchtower on Magua, the deployment happens the moment `:latest` is pushed** (the push of the merge of #17 / `4af08a0` may already have happened). To control it, pin the service to an explicit `:<BUILD_NUMBER>` tag, or add the label `com.centurylinklabs.watchtower.enable=false` to the container, before the build is pushed.
- The API runs Alembic migrations **automatically on startup** (README). Starting the new image is what migrates the DB, so the backup must come first.
- The target host is not decided (see unknowns). Per notes, raspi-62 (.62) is obsolete and must not be used.
